# Task 2 — Deploy a Web Server on AWS EC2

## Objective

Deploy a web server on an AWS EC2 instance and make it accessible through the internet.

## Implementation

- AWS EC2
- Amazon Linux 2023
- t3.micro instance
- Nginx web server
- Security Group
- HTTP (Port 80)
- SSH (Port 22)

## Result

The Nginx web server was successfully deployed on an AWS EC2 instance and accessed through its public IPv4 address.

Evidence screenshots are included in the `screenshots` folder.
